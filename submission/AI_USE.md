# AI use disclosure

Keel was built with substantial help from an AI coding assistant. This is what it did and did not do.

| Tool | Used for |
|---|---|
| Claude (Anthropic), run as the Claude Code agent | Wrote the application code (TypeScript, React), the research code (Python: simulator, baselines, detectors, evaluation), the tests, the documentation and the first drafts of every text in this submission, under the team's direction. |
| Claude research sub-agents | Read the NASA, ESA and journal sources and the dataset hosts, and produced `docs/DOMAIN.md` and `docs/DATA.md`. Every cited source was opened by the agent; nothing is cited from memory. |
| Claude review sub-agents | More than ten rounds of role-played review, each with fresh reviewers, (a flight surgeon, a statistician, an astronaut, a judge) critiqued the deployed app and the analysis. Analysis choices changed during these rounds and nothing was pre-registered. Their findings and what was changed are in `docs/REVIEW.md`. |

What AI did **not** do:

- **No AI model runs inside Keel.** Detection is robust statistics; advice comes from a fixed,
  human-readable rule table. No language model generates or rephrases any health text shown to a user.
- **No result was generated by an AI model.** Every number comes from the scripts in
  `research/scripts/` run on the datasets named in the README, and can be reproduced with `make all`.
- **No image, logo, audio or video was AI-generated.** The Keel mark is a hand-specified SVG. No NASA
  logos or insignia are used.
- **No data was fabricated.** Simulated data is produced by the documented simulator and is labelled
  as simulated wherever it appears.
- **No clinical review.** The role-played reviewers are AI, not clinicians. No clinician has reviewed
  anything.

Human responsibilities: choosing the problem and scope, checking the results, the final wording of the
submission, recording the demo, and everything listed under "needs a human" in `FINAL_REPORT.md`.
